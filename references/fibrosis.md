# PPF / IPF / CTD-ILD 选题深化清单

凡肺纤维化选题，按本清单追问。目的不是把每个研究做成同一种设计，而是防止诊断、时间和终点错位。指南和药物证据持续更新，定稿前必须核对当前原文。

## 1. 先定位研究问题

用一句话分清研究对象与层级：

- **疾病**：IPF、非 IPF ILD、PPF、某种 CTD-ILD，还是未分类 ILD？
- **临床环节**：筛查、确诊、MDD、进展识别、启动治疗、联合/序贯、减停药、急性加重、移植/姑息？
- **问题类型**：疗效、安全性、诊断、预后、治疗效应预测、表型、机制、测量、实施？
- **临床动作**：结果出来后，谁会在何时改变什么决策？

不要把“寻找 PPF 的生物标志物”当作已定问题。继续问：用于早诊、预测进展、预测药物获益，还是替代 FVC 随访？目标使用场景决定设计。

## 2. 人群与诊断

### PPF

- PPF 是一组非 IPF ILD 的**进展行为表型**，不是单一疾病；列出基础 ILD 构成与各亚型比例。
- 记录所用进展定义、满足定义的时间窗，以及如何排除感染、心衰、肺栓塞、药物毒性、暴露等其他解释。
- 区分“基线已达到 PPF”“随访中新发 PPF”“高进展风险但尚未 PPF”。三者不能共用一个含糊的 T0。
- 基础 ILD 构成若与既有试验明显不同，结果可能不同；这既可能是新意，也可能是不可比性，需明确论证。

### IPF

- 记录诊断依据与置信度：HRCT 模式、病理（如有）、MDD，以及是否排除其他已知原因。
- 关注合并肺气肿、肺高压、阻塞性通气障碍等，它们可使 FVC/6MWD/症状的解释改变。
- 区分新诊断与既往长期患病/长期用药队列，避免病程和幸存者差异。

### CTD-ILD

- 不能只写“CTD-ILD”：至少列出 SSc、RA、IIM、MCTD、SjD、SLE 等构成；必要时区分 IIM 亚型和抗体表型。
- 记录 CTD 病程、ILD 相对 CTD 的起病时间、系统活动度、自身抗体、皮肤/肌肉/关节活动和既往免疫抑制。
- 区分 CTD 肺外活动与肺纤维化进展；全身炎症改善不必然意味着纤维化改善。
- 记录筛查发现的无症状 ILD 与有症状/进展 ILD，避免谱系混杂。
- MDD 最好包含呼吸、风湿、影像，必要时病理；回顾性编码不能自动等于 MDD 确诊。

### 所有纤维化研究都要问

- 诊断是否在随访中重分类？重分类者如何处理？
- 不同中心/阅片者的 HRCT 模式与进展判定一致性如何？
- 是否需要中心复核或敏感性分析：仅高置信度病例、排除未分类 ILD、按基础病分层？

## 3. 干预与背景治疗

- **抗纤维化**：药物、剂量、启动/停药日期、减量、依从性、不良反应和既往暴露。
- **免疫抑制**：糖皮质激素、吗替麦考酚酯、环磷酰胺、他克莫司、利妥昔单抗、托珠单抗、JAK 抑制剂等按具体 CTD 记录；不能把“有/无免疫抑制”当二分类后就结束。
- **联合与序贯**：先免疫后抗纤维化、同步启动、因进展加药、因毒性换药，其时间顺序决定因果解释。
- **非药物**：康复、氧疗、疫苗、戒烟与暴露控制、营养、移植评估、姑息支持可能影响症状和事件。
- **对照**：核对当前指南与真实实践；历史对照的背景治疗、诊断标准和随访强度常不同。
- **感染**：免疫抑制与抗感染治疗、预防策略、病原检测要纳入安全性和急性呼吸事件鉴别。

追问：研究的是药物本身效应、治疗策略效应，还是某类患者中的实施效果？对应不同的随机化/观察设计和 estimand。

## 4. 结局与测量

| 结局 | 必问问题 |
|---|---|
| FVC | 用绝对 mL 变化、%变化还是 %预计值？预计值公式与质控是否一致？检查间隔和重复测量如何处理？ |
| DLCO | 是否校正血红蛋白？极低值/无法完成者如何处理？合并肺气肿/肺血管病如何解释？ |
| 6MWD | 吸氧、助行器、测试流程是否统一？不能完成者是否代表更严重结局而非简单缺失？ |
| HRCT | 视觉评分还是定量？扫描参数、阅片者一致性、肺气肿/感染干扰如何处理？ |
| 症状/PRO | 选 K-BILD、SGRQ、LCQ、呼吸困难量表等的理由？最小重要差异、语言版本和完成偏倚？ |
| 进展 | 采用哪个复合定义？各组分临床意义是否相同？是否包含死亡，如何处理？ |
| AE-ILD | 定义与排除诊断是否明确？感染、心衰、肺栓塞和药物毒性如何鉴别？ |
| 硬结局 | 住院、移植、呼吸死亡、全因死亡来源是否可靠？移植是结局、竞争事件还是治疗？ |
| 安全性 | 停药、减量、严重不良事件、感染、肝毒性、体重/营养与耐受性是否纳入？ |

核心提醒：短期 FVC 斜率、影像评分或症状改善不自动等于延缓移植/死亡。主要终点应对应研究声称能改变的临床决策。

## 5. 时间轴

在图上标出：症状起始 → CTD/ILD 诊断 → 首次 HRCT/PFT → 满足 PPF/进展定义 → 治疗启动 → 入组 → 随访 → 事件。

- **T0 唯一且可复现**：诊断日、用药初启日、landmark 日或达到进展定义日，不能混用。
- **暴露定义避免 future information**：入组后才发生的用药、检查或反应不能用于定义基线组。
- **检查窗口**：将不规则随访归入窗口时，说明窗口宽度和敏感性分析。
- **轨迹**：单次基线值不能代表进展速度；既往斜率可能需要入组前数据，但要避免因此选择“能活到有多次检查”的人。
- **事件率**：急性加重、住院、移植、死亡和失访的时间关系要明确。

## 6. 常见偏倚与应对

| 风险 | 典型场景 | 应对方向 |
|---|---|---|
| 适应症混杂 | 病情更重者更可能联合治疗，粗比较显示“治疗更差” | 明确治疗指征，调整预后因素；倾向评分/目标试验模拟；敏感性分析 |
| Immortal time | 按随访中是否加药分组，却从基线计算生存 | 时间依赖暴露、landmark 或 cloning-censoring-weighting 等合适设计 |
| Prevalent-user | 纳入长期耐受用药者与用药初启者比较 | 新使用者设计或分层，记录既往暴露 |
| Depletion of susceptibles | 早期不耐受/死亡者已离开队列 | 明确幸存队列外推边界，优先新使用者 |
| 反向因果 | 低体重/低 FVC 是不良预后原因还是疾病结果 | 时间顺序、滞后分析、纵向模型 |
| Regression to the mean | 因一次异常 FVC 下降入组，下次自然回升 | 重复确认、参考既往轨迹、随机/对照 |
| Informative missingness | 最重者无法完成 PFT/6MWD，数据“缺失”反而提示高风险 | 联合建模、复合结局、多重插补与极端情景敏感性分析 |
| 竞争风险 | 非呼吸死亡或移植阻止观察到 ILD 进展 | 明确 estimand；竞争风险/多状态模型，避免简单删失 |
| 诊断/中心效应 | 各中心 MDD、扫描、PFT 与治疗习惯不同 | 中心分层/随机效应、统一质控、外部验证 |
| 数据泄漏 | 用结局后的重复 PFT/影像特征训练预测模型 | 严格按预测时点截断特征，患者级独立验证 |
| 预后≠预测 | 标志物与差预后相关，就宣称能选药 | 需要治疗×标志物交互及适当对照/设计 |

## 7. 高价值问题来源（用于启发，不直接当答案）

- **精准启动**：谁应尽早启动抗纤维化或强化免疫抑制，谁可安全观察？临床动作和阈值是什么？
- **进展表型**：FVC、DLCO、HRCT、症状不同步时，哪种轨迹对应不同机制或硬结局？
- **联合/序贯**：CTD-ILD 中免疫抑制与抗纤维化的最佳时机、顺序和人群，而非简单“联合是否更好”。
- **减停与耐受**：长期稳定者能否减量？高龄、虚弱或低体重者如何兼顾疗效与耐受？
- **急性加重**：能否在感染等竞争原因之外识别真正 AE-ILD 高风险者，并触发可执行干预？
- **家庭监测**：家庭肺量计、脉氧、活动和 ePRO 能否改善临床结局，而不只是提高 AUC？
- **测量创新**：定量 HRCT/数字指标能否在特定场景补充或替代部分随访，测量误差和临床净获益如何？
- **真实世界外推**：RCT 排除的高龄、严重肺功能受损、复杂 CTD/合并症患者中，效果与风险是否不同？

每个方向都必须再落到具体 PICO/T0/终点，不能把热点名词当研究问题。

## 8. 定稿前快速检查

- [ ] 基础 ILD/CTD 构成清楚，PPF 未被当作单病。
- [ ] 诊断与 MDD/HRCT/PFT 标准可追溯，重分类有处理方案。
- [ ] T0、暴露、入组和随访时间轴无 future information。
- [ ] 背景治疗、既往治疗、减停药和依从性已定义。
- [ ] 主要终点与临床主张一致，测量质控和缺失机制可解释。
- [ ] 急性呼吸事件已考虑感染、心衰、肺栓塞等替代解释。
- [ ] 移植、死亡、失访与无法完成检查未被简单当作随机删失。
- [ ] 与最接近试验/队列的差异经原文和注册记录核实。
- [ ] 连续病例抽查支持病例数、事件数和变量完整度。
- [ ] 最终结论只外推到实际纳入的人群、场景和时间范围。
